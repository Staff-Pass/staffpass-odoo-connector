Safe payroll journals from StaffPass to Odoo

Import balanced payroll journal entries as drafts with company isolation, deterministic idempotency, account validation, analytic cost centers and an audit log.

Draft by design

Every imported journal remains in draft for accounting review and approval in Odoo.

Idempotent imports

Repeated delivery returns the existing move. Changed content under the same external ID is rejected.

Multi-company controls

Only explicitly enabled companies and journals can receive data from the dedicated integration user.

Accounting safeguards

  • Validates contract version, currency, civil date and balanced totals.
  • Resolves active accounts by code inside the configured Odoo company.
  • Maps optional cost center codes to active analytic accounts.
  • Rejects missing, ambiguous, inactive or cross-company mappings.
  • Serializes concurrent imports and keeps a durable audit record.
  • Creates safe reversal drafts without overwriting the original move.

Requirements

  • Odoo 19 Community or Enterprise on Odoo.sh or on-premise.
  • Odoo Accounting installed.
  • A StaffPass company with payroll accounting integration enabled.
  • A dedicated Odoo integration user and API key with minimum required permissions.
This module requires the external StaffPass service. It does not post entries automatically, transmit payroll from Odoo, or replace an accountant's review.
